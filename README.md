# Miranda in Japan · 2026

手机端优先的东京段交互式旅行网页，基于 `trip.md` 重新检查了路线逻辑后生成。

## 本地运行

推荐用本地服务器打开，避免浏览器限制地图或 JSON 资源：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

也可以直接打开 `index.html`，页面数据已内嵌，不依赖构建步骤。

## 文件

- `index.html`：可直接预览的旅行网页，包含 Leaflet 地图、每日路线、导航按钮、穿搭和拍照建议。
- `data/itinerary.json`：结构化行程备份，方便后续迁移到 Next.js 或继续扩展京都/大阪/USJ。
- `trip.md`：原始需求与行程草案。
